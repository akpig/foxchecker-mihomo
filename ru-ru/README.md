# foxchecker-mihomo

[English](../README.md) · [简体中文](../zh-cn/README.md) · [繁體中文](../zh-hant/README.md) · [日本語](../ja/README.md) · **Русский** · [Türkçe](../tr-tr/README.md) · [Tiếng Việt](../vi-vn/README.md) · [العربية](../ar/README.md) · [فارسی](../fa-ir/README.md) · [اردو](../ur-pk/README.md)

Foxchecker использует ядро Mihomo для проверки прокси-узлов из ссылок и подписок. В отчёте указаны доступность HTTPS, входной IP-адрес, фактический выходной IP-адрес, страна или регион по GeoIP, а также отдельные результаты UDP4 и UDP6. Скрипт использует готовый образ и требует запущенного Docker. [Образ на Docker Hub](https://hub.docker.com/r/akpig/foxchecker-mihomo)

## Быстрый старт

Нужны Bash, доступ к Docker с поддержкой Linux-контейнеров и каталог отчётов с правом записи. Образ предназначен для `linux/amd64`. На хостах ARM Docker должен поддерживать запуск контейнеров amd64. Движку Docker требуется доступ к каталогу отчётов и локальному файлу подписки на хосте.

### Запуск напрямую с GitHub

Выполняйте команды в каталоге, где хотите сохранить отчёт. Они загружают `mihomo-checker.sh` из ветки GitHub по умолчанию. Аргументы после `bash -s --` передаются скрипту.

```bash
curl -fsSL 'https://raw.githubusercontent.com/akpig/foxchecker-mihomo/main/mihomo-checker.sh' | bash -s -- 'vmess://…'
curl -fsSL 'https://raw.githubusercontent.com/akpig/foxchecker-mihomo/main/mihomo-checker.sh' | bash -s -- -s 'https://sub.foxdetector.com/ru-ru/top500/clash.yaml'
```

### Запуск локальной копии

Выполните команды из каталога репозитория, заменив примеры своими данными. Чтобы сохранить отчёт в другом месте, перейдите в нужный каталог и запустите скрипт по абсолютному пути.

#### Проверка одной ссылки

```bash
./mihomo-checker.sh 'vmess://…'
```

Поддерживаются схемы `vmess://`, `vless://`, `trojan://`, `ss://`, `hysteria2://` (`hy2://`), `tuic://`, `anytls://`. Доступные транспорты зависят от поддержки конфигурации узла в Mihomo.

#### Проверка подписки

```bash
./mihomo-checker.sh -s 'https://sub.foxdetector.com/ru-ru/top500/clash.yaml'
./mihomo-checker.sh -s './clash.yaml' --format clash -c 8 --timeout 15s
```

Параметр `-s` принимает общедоступный URL HTTPS или локальный файл. Относительные пути вычисляются от текущего каталога. Формат определяется автоматически. Поддерживаются Clash YAML со встроенными узлами, списки ссылок V2Ray в тексте или Base64 и JSON для sing-box.

| Параметр | Назначение |
| --- | --- |
| `-s`, `--subscription` | Указать URL или локальный файл подписки |
| `-c`, `--concurrent` | Максимум одновременных проверок подписки, по умолчанию `16` |
| `--format` | Формат подписки, по умолчанию `auto`. Допустимы `clash`, `v2ray` и sing-box. |
| `--timeout` | Тайм-аут на узел, по умолчанию `10s`. Действует для одной ссылки и подписок. |
| `-h`, `--help` | Показать справку |

## Просмотр результатов

Скрипт записывает `result.json` в текущий каталог и заменяет его при создании нового отчёта. Для одной ссылки результат узла записывается напрямую. Для подписки результаты перечислены в `results` в порядке входных данных. При ошибке проверьте `error.code` и `https.reason`. Значение `null` в поле UDP означает, что результат не определён. Подробности см. в `udp4_reason` или `udp6_reason`.

Скрипт использует `akpig/foxchecker-mihomo:latest`. При отсутствии локального образа Docker загрузит его. После завершения или прерывания проверки скрипт удаляет контейнер. При сбое скрипт возвращает ненулевой код выхода и по возможности записывает причину в отчёт. Если Docker не запускается или команда задана неверно, в каталоге может остаться предыдущий `result.json`. Сверяйте код выхода и вывод терминала.

## Локальная сборка образа

Поместите исполняемый файл Foxchecker для Linux amd64 по пути `foxchecker/foxchecker` и выполните команду из каталога репозитория.

```bash
./build.sh
```

Скрипт сборки обновляет и проверяет данные GeoIP, затем создаёт локальный образ `foxchecker-mihomo:latest`. Скрипт проверки использует образ Docker Hub по ссылке выше. Сведения об источнике GeoIP см. в [geoip/NOTICE](../geoip/NOTICE).
